HENZO STORE — MÔ TẢ API
==============================================================================

Base URL (Render)   : https://henzo-store.onrender.com/api
Base URL (local)    : http://localhost:4000/api
Tổng số endpoint   : 85

QUY ƯỚC CHUNG
------------------------------------------------------------------------------
  • Mọi endpoint trả về JSON với cấu trúc:
      Thành công : { "success": true, "data": ..., "meta"?: {...} }
      Thất bại  : { "success": false, "data": null, "error": { "code", "message" } }
  • Phân trang: tham số "page" (mặc định 1) và "pageSize" (mặc định 20).
      Kết quả nằm trong "meta": { page, pageSize, total, totalPages }.
  • Xác thực: gửi header "Authorization: Bearer <access_token>".
      Access token nhận từ POST /api/auth/login hoặc POST /api/auth/refresh.
      Refresh token nằm trong cookie httpOnly "henzo_refresh_token" (path=/api/auth).
  • Quyền truy cập:
      - Công khai  : không cần token
      - [AUTH]     : cần đăng nhập
      - [ADMIN]   : role ADMIN / MODERATOR / STAFF
      - [SELLER]  : role SHOP, chỉ thao tác dữ liệu của chính cửa hàng

MÃ LỖI THƯỜNG GẶP
------------------------------------------------------------------------------
  400 BAD_REQUEST     — dữ liệu gửi lên không hợp lệ
  401 UNAUTHORIZED   — chưa đăng nhập hoặc token hết hạn
  403 FORBIDDEN      — đã đăng nhập nhưng không đủ quyền
  404 NOT_FOUND      — không tìm thấy dữ liệu
  500 INTERNAL_ERROR — lỗi máy chủ

VÍ DỤ GỌI API
------------------------------------------------------------------------------
  # Đăng nhập -> lấy access token
  curl -X POST https://henzo-store.onrender.com/api/auth/login \
    -H "Content-Type: application/json" \
    -d '{"email":"customer@henzo.com","password":"123456"}'

  # Gọi endpoint cần xác thực
  curl https://henzo-store.onrender.com/api/cart \
    -H "Authorization: Bearer <access_token>"

  # Danh sách sản phẩm có lọc + phân trang
  curl "https://henzo-store.onrender.com/api/products?category=iphone&minPrice=10000000&page=1&pageSize=5"

  # Response mẫu (GET /api/products)
  {
    "success": true,
    "data": [ { "id": "...", "name": "iPhone 15 Pro Max 256GB", "price": 29990000, ... } ],
    "meta": { "page": 1, "pageSize": 5, "total": 570, "totalPages": 114 }
  }

  # Response mẫu khi lỗi
  {
    "success": false,
    "data": null,
    "error": { "code": "UNAUTHORIZED", "message": "Chưa đăng nhập" }
  }

PROXY ẢNH  (/api/image)
------------------------------------------------------------------------------

  [  2] GET  /api/image

      GET
        Proxy ảnh Wikimedia. Nhận URL ảnh gốc, trả về ảnh đã cache trên server — tránh bị Wikimedia chặn 429 khi nhiều người xem cùng lúc.

XÁC THỰC & TÀI KHOẢN  (/api/auth)
------------------------------------------------------------------------------
  Đăng ký, đăng nhập, làm mới token, hồ sơ. Access token trả về trong body, refresh token nằm trong cookie httpOnly (path=/api/auth).

  [  3] POST  /api/auth/login

      POST
        Đăng nhập. Trả access token trong body và set cookie refresh token (httpOnly).

      Body (POST):
      email — Email
      password — Mật khẩu

  [  4] POST  /api/auth/logout

      POST
        Đăng xuất — xoá cookie refresh token và vô hiệu hoá refresh token hiện tại.

  [  5] GET  /api/auth/me [AUTH]

      GET
        Lấy thông tin người dùng đang đăng nhập (hồ sơ, vai trò, quyền).

  [  6] POST  /api/auth/password [AUTH]

      POST
        Đổi mật khẩu. Yêu cầu mật khẩu hiện tại và mật khẩu mới tối thiểu 6 ký tự.

      Body (POST):
      currentPassword — Mật khẩu hiện tại
      newPassword — Mật khẩu mới
      confirmPassword — Xác nhận mật khẩu mới

  [  7] PATCH  /api/auth/profile [AUTH]

      PATCH
        Cập nhật hồ sơ (tên, email, số điện thoại, ảnh đại diện, địa chỉ).

      Body (PATCH):
      name — Tên
      email — Email
      phone — Số điện thoại
      avatar — URL ảnh đại diện
      address — Địa chỉ đầy đủ
      province — Tỉnh / Thành phố
      district — Quận / Huyện
      ward — Phường / Xã

  [  8] POST  /api/auth/refresh

      POST
        Làm mới access token bằng cookie refresh token. Dùng khi access token hết hạn.

  [  9] POST  /api/auth/register

      POST
        Đăng ký tài khoản khách hàng. Role luôn là CUSTOMER, không nhận role từ client.

      Body (POST):
      name — Tên
      email — Email
      phone — Số điện thoại
      password — Mật khẩu
